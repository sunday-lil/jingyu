## 三、注意事项

1. **格式**：mp3 最省事；flac/wav/m4a 先转成 mp3，文件名保持曲名。
2. **文件名必须与上表完全一致**（含中文），放错名字网页会 404。
3. **版权**：搜到的录音仅作个人使用；公开部署前确认授权。
4. **放置目录**：项目根目录下的 `static/audio/tracks/`（相对路径，不要写死本机绝对路径）。
5. 放进 git：
   ```
   git add static/audio/tracks
   git commit -m "feat(music): add real audio tracks"
   git push origin main
   ```
