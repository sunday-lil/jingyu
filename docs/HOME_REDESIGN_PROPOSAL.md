## 一、产品定位（源自《网站.docx》，一字不改的原文要义）

> 给每一个用户建立一个**属于自己且相对私密的**、帮助处理消极情绪、建立健康身心的「**心灵港湾**」。

- **核心体验**：建立并完善自己的小岛——种花、购买宠物（动物装扮）和装饰
- **六个模块**：并行式的、达成上述目的的不同方式（听古琴 / 写日记 / 漂流瓶 / 给陌生人鼓励 / 记录心情 / AI 树洞）
- **资源闭环**（已上线）：岛上活动 → 露水 + 徽章 → 落叶 → 兑花种 → 露水浇灌 → 花朵装饰岛屿
- **新增粘性层**：小岛等级——做活动攒经验 → 升 Level → 解锁新花种 / 更高级古琴曲

## 三、首页改造方案（第一期，纯前端）

### 3.1 Hero 理念文案（放动效图右侧/文字下方）

桌面端 hero 左右分栏（左：场景+大字；右：理念文案卡）；移动端上下堆叠。文案草案：

> **每一个情绪，都值得一座岛。**
>
> 静屿是一座只属于你的心灵港湾——
> 在这里听一曲古琴，写一封漂流的信，
> 把说不出口的，种成一朵会开的花。
>
> 🔒 日记端到端加密 · 无广告 · 无算法推荐

（末行三个信任点直接回应「私密港湾」定位）

### 3.2 模块区（保持并行同级，卡片加「怎么玩」）

六卡布局不变（并行同级是明确意图），每张卡片 desc 下加一行奖励提示（复用 GUIDE_SECTIONS 数据）：

```
🎵 琴音疗心          宫商角徵羽 · 古琴五音调情志
   每听一曲 +1 露水 · 听满10首解锁「琴音知音」徽章
```

### 3.3 岛上指南区块（新增）

位置：模块区下方。复用 `GUIDE_SECTIONS`（六个手风琴折叠面板），标题「岛上指南」+ 副标题「每个去处怎么玩，一目了然」。不跳页、不打断。

### 3.4 动线逻辑

不设单一主推按钮（并行同级）。未登录主 CTA = 「开启我的岛」→ /register（小岛建设是主推，注册即得到自己的岛）；听曲作为零门槛体验保留在模块卡第一位。

## 四、小岛等级系统设计草案（第二期，前后端）

### 4.1 数据模型

```python
# User 表新增（_migrate_legacy_columns 加列，老用户自动补算）
island_level: int = 1        # 小岛等级
island_exp:   int = 0        # 当前经验值
```

新建 `app/services/level_service.py`：`add_exp_and_check_level()` 在现有各活动入口（听曲/日记/打卡/树洞/鼓励/种花）埋点，与露水发放同事务。

### 4.2 经验值草案

| 行为 | 经验 | 备注 |
|---|---|---|
| 听完一曲 | +2 | 与露水同源 |
| 写一篇日记 | +5 | |
| 心情打卡 | +3 | 每次都算（情绪多变） |
| 树洞对话 | +3 | 每轮 |
| 给陌生人鼓励 | +2 | |
| 种下一朵花 | +10 | |
| 解锁一枚徽章 | +20 | 一次性 |

### 4.3 升级阈值（草案）

```
L1→L2: 30   （当天可达，首日正反馈）
L2→L3: 50
L3→L4: 80
L4→L5: 120   …每级 +40% 递增，封顶 L10
```

升级时刻：全站轻提示（toast）「你的小岛升到了 Lv.3」；花田页加等级木牌。

### 4.4 解锁门控（⚠️ 需拍板的张力点）

| 门控对象 | 建议 |
|---|---|
| **花种分档** | 11 种花分四档：基础（向日葵/竹子/雏菊，L1）→ 中级（莲花/薰衣草/郁金香，L2-3）→ 高级（樱花/桃花，L4-5）→ 珍稀（青松/小麦/青叶，L6+） |
| **五音古曲** | **建议永不锁定**——疗愈是底线：用户深夜焦虑点进来发现曲子锁着，违背「心灵港湾」初心 |
| **西洋曲谱** | 可作为 L3 解锁的「岛上的惊喜」（非核心疗愈路径） |

### 4.5 经验回溯

老用户上线时按现有统计（听曲数/日记数/徽章数）一次性补算 exp 和 level，不白干。
