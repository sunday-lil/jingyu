## 问题 1：Safari 主页 3D 不渲染

### 根因
1. hasWebGL() 检测 bug：instanceof WebGLRenderingContext 对 WebGL2 context 返回 false
2. iOS Safari 17 切后台→前台必丢 WebGL 上下文，无恢复逻辑→永久黑屏
3. PMREM/UnrealBloomPass 依赖 EXT_color_buffer_half_float，老 iOS 缺失→静默失败
4. iOS 内存上限 ~384MB，高 DPR + 2048 shadow + 256 PMREM + 3 bloom RT 易 OOM

### 修复
- visual.js：重写 hasWebGL()，明确区分 WebGL1/2 + 检测 half-float 扩展 + max texture size
- visual.js：新增 getWebGLCaps() / isSafari() / isIOS()
- three-helpers.js：createRenderer() 加 webglcontextlost/webglcontextrestored 监听 + preventDefault
- HeroScene.vue：
  - iOS 直接关 Bloom（避免 HalfFloat RT 触发上下文丢失）
  - iOS PMREM 降到 128 + shadow 降到 1024 + dpr 1.5
  - 老 Safari 缺 half-float → 关 PMREM + Bloom
  - 上下文恢复后自动重新初始化场景
  - 失败兜底 SVG fallback

## 问题 2：Safari emoji 显示不同

### 根因
- Safari 用 Apple Color Emoji，Chrome 用 Segoe UI Emoji / Noto，设计风格差异大
- 🥀 等 emoji 跨平台视觉差异极大（Apple 枯玫瑰 vs Google 带叶玫瑰）
- @font-face 加 emoji 字体在 Safari 上有字距 bug

### 修复
- 新建 EmojiIcon.vue 组件：用 Iconify + @iconify-json/twemoji（离线 SVG）
- SVG 矢量，与系统 emoji 字体无关，所有浏览器渲染一致
- Vite 构建时按需 tree-shake，0 运行时 HTTP
- AppLayout.vue：替换导航品牌🏝️ + 6 导航项 emoji + 🔔 + 💧（桌面/平板/移动端三套）
- ProfileView.vue：替换头像🏝️ + 通知🔔 + 资源💧🍂 + 6 统计卡片 + 5 快捷入口 + 动态花朵阶段 emoji
